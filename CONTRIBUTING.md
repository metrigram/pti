# Contributing

This repository is a reference implementation maintained by Hector Trevino (metrigram). It is not currently accepting pull requests.

If you find a bug in the implementation, open an issue and describe it. Ports to other languages are welcome as forks — if you build one, feel free to open an issue to have it linked from the README.

For questions about the PTI specification, see the paper or reach out via metrigram.com.
